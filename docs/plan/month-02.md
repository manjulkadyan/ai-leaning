# Month 2: Calculus, Probability, Statistics, Optimization

**Goal.** Understand the mathematics of *learning*: how a model measures its error, how the derivative tells it which way to change, and how to reason about data that is noisy and uncertain.

**Milestone.** Train a linear regression on the Play Store dataset with gradient descent whose gradients you derived by hand, verify them against a numerical gradient check, and get the mean squared error on a held-out test set below a target you set from a baseline.

Lessons marked *coming soon* are being written; the plan is fixed so you can see what's ahead. The rhythm is the same as Month 1: six study days, one rest day.
