# Month 1: Python, NumPy, pandas, Linear Algebra

**Goal.** Become fluent enough in Python and NumPy that the tools disappear, and understand vectors and matrices well enough to read any ML equation.

**Milestone.** (1) Implement matrix multiplication, transpose and norms in plain Python, then show NumPy gives the same results 100× faster. (2) Clean a real dataset with pandas and answer five questions with five plots.

Lessons marked *coming soon* are being written; the plan is fixed so you can see what's ahead.
