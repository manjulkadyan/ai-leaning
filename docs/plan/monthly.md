# Monthly Plan

Twelve months, each with a goal, the roadmap modules it covers, and a measurable milestone. Months 1 and 2 are planned day by day already; later months get their daily plans as the course is written.

| Month | Focus | Modules | Milestone (measurable) |
|---|---|---|---|
| 1 | Python, NumPy, pandas, linear algebra | 1.1–1.5 | NumPy matrix ops from scratch; a cleaned pandas dataset with 5 plots answering real questions |
| 2 | Calculus, probability, statistics, optimization | 1.6–1.10 | Linear regression trained with hand-derived gradient descent, loss below a target on a held-out set |
| 3 | Classic machine learning | 2.1–2.10 | Tabular project: 3 models compared with 5-fold CV, metric choice justified, error analysis written |
| 4 | Neural networks and PyTorch | 3.1–3.7 | Micro-autograd engine that trains an MLP; the same MLP in PyTorch reaching ≥97% on MNIST |
| 5 | CNNs, embeddings, transformers | 3.8–3.12 | MobileNet transfer-learned classifier; character-level GPT generating text from scratch |
| 6 | How LLMs work | 4.1–4.8 | Tokenizer trained from scratch; LoRA fine-tune with before/after eval numbers |
| 7 | Building with LLMs | 4.9–4.13 | RAG Q&A app with a 50-question eval set and a measured accuracy number |
| 8 | AI engineering in production | 5.1–5.10 | RAG app deployed in a container with tracing, CI evals, cost and latency dashboard |
| 9 | On-device foundations | 6.1–6.7 | Android app running a quantized LiteRT classifier on GPU; benchmark table CPU vs GPU |
| 10 | On-device LLMs and multimodal | 6.8–6.13 | Offline on-device LLM feature in the app; latency, memory and battery measured on 2 devices |
| 11 | Advanced topics and research | 7.x (pick 2), 8.1–8.4 | Specialization project; one paper result reproduced and written up |
| 12 | Open source and career | 8.5–8.6, 9.1–9.6 | One merged OSS PR; portfolio published; 5 mock system-design interviews done |

## Checkpoints

At the end of months **3, 6, 9 and 12**, take a half-day to:

1. Re-read the roadmap and mark which modules feel solid, shaky, or unknown.
2. Spend the following week's review days on the shaky ones.
3. Update your portfolio README with what you can now do.
